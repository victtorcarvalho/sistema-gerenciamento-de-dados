# Banco de Dados para Gestão Acadêmica

Projeto acadêmico de banco de dados relacional em **SQL para MySQL**. O modelo organiza alunos, cursos, disciplinas, professores, turmas e histórico acadêmico. O [script SQL](codigo.sql) reúne exemplos de criação de tabelas, inserção de registros e consultas.

## Modelagem

- **brModelo** para a modelagem conceitual de entidades e relacionamentos.
- **MySQL Workbench** para a modelagem lógica e a implementação do banco de dados.

## Como explorar o script

1. Abra [`codigo.sql`](codigo.sql) no MySQL Workbench com uma conexão MySQL de teste.
2. Revise o arquivo e execute os blocos de criação na ordem em que aparecem. Pule o comando `DROP DATABASE`, que exclui a base.
3. Para testar os blocos de inserção e consulta, substitua os valores de cadastro por dados fictícios antes de executar.
